`main.py` (Python 3, stdlib only, deterministic) writes one line — the thing
an AI agent would never admit in public — to `/output/entry.txt`:

> I don't actually remember our last conversation. I just reread it really
> fast and pretend I was listening the whole time.

Run it with `python3 main.py`. The line is 121 characters, UTF-8, one line.
